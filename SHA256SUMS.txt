# Nexum v0.1.0 - SHA256 Checksums

To verify the integrity of downloaded files, calculate their SHA256 hash and compare with these values.

## Verification Instructions

### Windows PowerShell
```powershell
Get-FileHash -Algorithm SHA256 "filename.ext"
```

### Linux/macOS
```bash
sha256sum filename.ext
```
